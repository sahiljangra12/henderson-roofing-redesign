# DM Henderson Roofing — Redesign Concept

An unofficial, SpaceX-style redesign concept for [DM Henderson Roofing Ltd.](https://hendersonroofing.com) (Dawson Creek, BC). Not affiliated with or endorsed by the company.

Single self-contained `index.html`: full-screen photo panels, Ken Burns hero slideshow, word-by-word headline reveals, filterable project gallery with lightbox, animated timeline and counters. Photos and logos load from the company's existing website.
